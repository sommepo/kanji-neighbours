# Config

Use **Tools → Add-ons → Kanji Neighbours → Config**.

| Key | Meaning |
|---|---|
| `word_fields` | Word field(s) to search |
| `reading_fields` | Reading |
| `definition_fields` | Definition |
| `sentence_fields` | Japanese sentence |
| `native_sentence_fields` | Native-language sentence |
| `word_selectors` | CSS selectors for the clickable word |
| `show_in_popup` | Which rows to show (`word`, `reading`, `definition`, `sentence`, `native`) |
| `note_type_map` | Per note type field overrides |
| `min_reps` | Minimum reviews (`prop:reps>=N`) |
| `deck_scope` | `current`, `deck_root`, or `collection` |
| `max_results` | Popup cap |
